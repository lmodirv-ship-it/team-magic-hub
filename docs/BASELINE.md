# NAWAT Studio — خط أساس القياس (P0)

لا تُعامل أهداف الأداء التالية على أنها نتائج: TTI < 1.5s، فتح p95 < 80ms، بحث 1000 ملف p95 < 500ms، استعادة < 200ms، ذاكرة 20 ملفًا < 600MB.

## تجربة أولية

- بيئة: Chromium headless، نافذة 1280×1800، مساحة العمل الافتراضية.
- محرر Monaco المحلي: ظهر بعد التحميل دون أخطاء JavaScript في تجربة المتصفح.
- بحث المحتوى: البحث عن `NAWAT` أعاد 6 نتائج في ملفات مساحة العمل الافتراضية.
- حفظ واستعادة: إضافة نص عربي إلى HTML، حفظ Ctrl+S، إعادة تحميل؛ بقي النص في التخزين وفي المحرر.
- فتح سريع Ctrl+P: ظهر حقل فتح الملفات بعد إعادة التحميل.

## قياسات لم تُجرَ بعد

فتح عشرة ملفات فعلية، حساب p50/p95/p99، قياس ذاكرة المتصفح، بحث 1000 ملف، اختبار Kill -9 للكتابة الذرية، وفحص طلبات الشبكة أثناء وضع عدم الاتصال. يتطلب اختبار الكتابة الذرية ربطًا حقيقيًا بقرص نسخة سطح المكتب قبل القياس.
